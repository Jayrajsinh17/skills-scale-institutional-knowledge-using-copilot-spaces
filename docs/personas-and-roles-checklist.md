# Persona & Roles Addition Checklist

Purpose: A short checklist template to validate and onboard new personas into the project lifecycle.

- [ ] Persona name and short role summary added to docs/octoacme-roles-and-personas.md
- [ ] Responsibilities and acceptance criteria documented
- [ ] Interaction map: list primary contacts (e.g., PM, PdM, Developer, SRE)
- [ ] Example artifacts and deliverables identified
- [ ] Owner (person) assigned for the persona (example: "Alice — Security Champion")
- [ ] Added to relevant project boards/README for visibility
- [ ] Reviewed by Product Lead / Project Manager / any impacted stakeholders
- [ ] Included in onboarding materials and the Project One-pager template
- [ ] Linked from release checklist and incident playbooks where relevant
